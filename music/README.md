# 背景音乐放这里

由于版权原因，仓库里不包含任何歌曲。请把你自己的正版音乐文件按下面的名字放进这个文件夹：

| 文件名 | 歌曲 | 用在哪一段 |
|---|---|---|
| `xinli.mp3` | 此刻你心里想起谁 | 序、海口、长大、我们遇见 |
| `bukesiyi.mp3` | 不可思议 | 2003.10.15 那一天（神舟五号 / 专辑发行 / 她出生） |
| `nibuzai.mp3` | 你不在 | 争吵（会被实时处理成“隔着墙”的闷声，雨停时慢慢变清楚） |
| `love.mp3` | 爱无所不在 | 彼此相爱、生日快乐 |

想换别的歌：只要改 `js/config.js` 里 `MUSIC.tracks` 的 `src` 和标题即可；想让某一段用别的歌，改 `index.html` 里那一段的 `data-track`。

**跳过前奏**：在 `js/config.js` 里设置每首的 `start`（从第几秒开始）和 `end`（播到第几秒回到 start 循环）。
不知道秒数就打开 `网址?tune`，边听边点“设为起点 / 设为终点”，面板会显示应该填的数字。

**想要真正剪好的“处理版本”**（文件更小、加载更快）：

```bash
tools/process-music.sh 原始文件.flac music/love.mp3 62 185 warm
```

文件缺失时网站会自动播放合成的氛围音，所以没放歌也能先预览效果。
