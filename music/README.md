# 背景音乐放这里

仓库里不含任何歌曲（版权原因）。每一章对应一个文件，放了哪个，哪一章就从网页合成曲换成真歌：

| 章节 | 文件名 | 建议 | 没放文件时的合成曲 |
|---|---|---|---|
| 序 | `xinli.mp3` | 此刻你心里想起谁 | Prelude · 序曲（八音盒） |
| 那一天 | `bukesiyi.mp3` | 不可思议 | Liftoff · 升空（明亮拨弦） |
| 从那天起 | `days.mp3` | 自选 | Tender · 时光（钢琴） |
| 长大 | `grow.mp3` | 自选 | Waltz · 长大（八音盒华尔兹） |
| 遇见 | `us.mp3` | 自选 | Sweet · 遇见（拨弦 + 钢琴） |
| 争吵 | `nibuzai.mp3` | 你不在 | Rain · 雨（小调钢琴） |
| 相爱 | `love.mp3` | 爱无所不在 | Everywhere · 相爱（铺底 + 铃音） |
| 生日快乐 | `bday.mp3` | 自选 | Celebrate · 生日（欢快八音盒） |

文件名、歌名、从第几秒开始（跳前奏）都在 `js/config.js` 的 `MUSIC.scenes` 里改。
两章用同一首歌：把 `src` 写成同一个文件就行，`start` 也相同时会接着放，不会重头开始。

不知道副歌从第几秒开始：打开 `网址?tune`，边听边点“设为起点 / 设为终点”。

想把歌剪成只含副歌的小文件（加载更快）：

```bash
tools/process-music.sh 原始文件.flac music/love.mp3 62 185 warm
```
